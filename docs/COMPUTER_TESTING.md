# NEXORA CORE 电脑测试说明

没有实体开发板时，电脑负责验证软件、协议、角色资源和数字样机。测试不会把尚未发生的实体实验标记为通过。

## 打开测试台

在仓库根目录启动 Netlify 本地环境：

```bash
npx netlify dev --port 8888
```

打开：

```text
http://localhost:8888/device-lab/
```

点击“运行全部测试”。测试台会并排显示 390×844 手机网关和 NC-01 项链端，并自动检查：

1. 双端页面、角色图片与 240×240 圆屏加载。
2. 虚拟 BLE 连接以及名字、成长形态、共鸣同步。
3. 单击亲近、双击开心、长按倾听，以及思考、说话等独立角色姿势。
4. 低电量、充电、休眠和断连状态。
5. 一轮真实连续对话、人格成长和云端音频返回。

## 命令行验收

```bash
npm run test:computer
```

该命令依次运行 Node 协议与数据测试、ESP32-S3 固件编译、STL 网格检查和 PETG 数字切片。数字切片需要本机安装 PrusaSlicer。

## 判定边界

电脑可通过：界面、对话、声线接口、角色资源、数据保存、圆屏安全区、BLE 数据格式、状态机、固件编译、网格闭合与切片路径。

没有实体样机时不能通过：电池温升与续航、真实麦克风回声、扬声器音质与共振、蓝牙距离、射频衰减、跌落、吊环拉力、绝缘和贴肤材料安全。
