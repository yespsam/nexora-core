# NC-01 EVT-A 首件采购与接线计划

版本：2026-08-03

## 结论

首轮不能把所有开发板直接塞进项链。当前服务仓为 `31.5 x 28 x 5.8 mm`，电池、麦克风开发板、功放开发板、扬声器和振动马达的矩形包络体积之和已达到服务仓的 `112.7%`，且还没有计入静音开关、状态灯、连接器、导线、公差和声腔。

因此首件拆成两个阶段：

- **EVT-A 桌面接线机**：验证屏幕、BLE、IMU、I2S 收音、I2S 播放、回声、震动和基本功耗。器件可以在外壳外连接。
- **EVT-B 佩戴集成机**：根据 EVT-A 结果设计一块小型音频/灯光/静音载板，选择可追溯电池并修改服务仓和声腔。

## 暂停采购项

电池暂不下单。目标是带保护板的单节 `3.7 V` 软包电池，初始包络约 `30 x 12 x 3 mm`，并使用 MX1.25 2P。下单前必须取得：

1. 电芯与保护板资料。
2. 连接器准确型号和线序照片。
3. 与 Waveshare 主板正负极逐线一致的确认。
4. 允许充电电流、工作温度和运输资料。

常见 JST-PH 电池不能因为“也是两针”就直接插入；连接器尺寸和极性都可能不同。第一次通电先使用 USB 或限流电源，电池最后接入。

物理静音开关、四段状态灯和安全脱离扣也暂不冻结。它们分别依赖电源门控、导光实测和拉力方案。

## EVT-A 引脚

| 信号 | GPIO | 方向 | 说明 |
| --- | ---: | --- | --- |
| I2S BCLK | 13 | 输出 | 麦克风与功放共享时钟 |
| I2S LRCLK | 14 | 输出 | 麦克风与功放共享帧时钟 |
| 麦克风数据 | 15 | 输入 | SPH0645LM4H DATA |
| 扬声器数据 | 16 | 输出 | MAX98357A DIN |
| 功放关断 | 17 | 输出 | MAX98357A SD |
| 状态灯数据 | 18 | 输出 | EVT 临时状态灯 |
| 静音状态 | 39 | 输入 | 只检测开关；开关还必须切断麦克风供电 |
| 震动 A / B | 4 / 5 | 输出 | 先核对实板 MOS 触点和极性 |

完整保留与冲突检查见 `hardware/soulmate-pendant/evt/nc01-pin-plan-v1.json`。GPIO45 和 GPIO46 不用于首件扩展。

## 到货验收

1. 核对每件型号、尺寸、数量、损伤和连接器。
2. 三块主板只接 USB，分别运行原厂屏幕和 IMU 检查。
3. 逐块刷入 NEXORA 固件，确认屏幕、54 套资源、BLE 广播和电池 ADC。
4. 只连接麦克风，完成固定语料录音；再单独连接功放和扬声器。
5. 最后连接震动马达，确认不会使主板复位或污染麦克风。
6. 全部桌面测试通过后才开始电池、外壳和贴肤相关实验。

任何接反、电池发热、异味、鼓包、主板复位或连接器温升都立即断电并记录，不继续佩戴测试。
