# NEXORA CORE 采购前验收报告

验收日期：2026-08-04

## 放行结论

**有条件放行一套桌面 EVT-A 验证件；不放行佩戴成品、三套复制、电池和量产采购。**

首轮只购买 `NC01_TAOBAO_PROCUREMENT.md` 中的六类 USB 供电台架器件，预算目标为 CNY 118-178（含预估运费）。这一步的目标是取得真实屏幕、BLE、IMU、麦克风、扬声器和震动数据，不是组装可佩戴商品。

## 本轮通过

- Node 自动化 `262/262` 通过，ESP32-S3 数字模拟通过。
- 固件编译通过：RAM 30828 / 327680 bytes（9.4%），Flash 632217 / 3145728 bytes（20.1%）。
- 浏览器静态验收 `14/16`：九形态 `9/9`、动作 `33/33`、18 组移动动作持续 30 秒、178 帧稳定，三端身份、电源状态和断连显示通过。
- 三路线真实声音均返回 `200 audio/mpeg`，合计 118656 bytes；可爱、帅气、优美路线使用不同声线。
- Kimi `kimi-k2.6` 三轮接口连续对话均返回 `200 cloud_llm`；Safari 私有分支实测也能记住“番茄牛腩、不吃香菜”，在追问中准确复述，并在用户改口后采用最新的“寿司”偏好。
- 手机 390 x 844、桌面主界面、240 x 240 圆屏模拟器和透明桌面宠物已完成软件侧检查。
- 无电池 USB 调试不再误报低电量；固件新增麦克风、扬声器、IMU、震动和静音输入台架诊断。

## 当前阻断

1. **实体硬件验收为 3/16。** 麦克风近讲、扬声器音质与回声、BLE 距离、真屏功耗、IMU 误唤醒、温升、续航、跌落、拉力和贴肤安全都需要实物。
2. **当前结构不是可佩戴成品。** 开发板器件最低包络已占服务仓 112.7%，还未计入连接器、线材、公差和声腔；EVT-A 通过后必须做 EVT-B 集成小板。
3. **项链固件的音频目前只有台架诊断。** 它能检查 INMP441 是否有采样、让 MAX98357A 播放测试音，但还没有把项链麦克风音频传给手机/云端，也没有在项链端播放伙伴的完整语音回复。
4. **手机端仍是网页网关原型。** iOS Core Bluetooth、Android BLE 插件、后台重连和真机权限尚未完成。
5. **家居控制仍是接口原型。** 尚无真实 Matter、Home Assistant 或小米设备命令回执。
6. **桌面安装包未完成外部分发签名。** macOS 尚未 Apple 公证，Windows 尚未 Authenticode 签名。

## 本轮修复

- 连续语音唤醒增加 20 秒会话看门狗，识别引擎无回调时自动中止并重启。
- 发送中的用户消息不再提前同步到其他窗口；云端失败时不会留下幽灵消息或错误增长人格。
- 固件在未接电池的 USB 调试状态显示 `USB`，不再逐步降到低电量。
- 淘宝方案、引脚计划和固件统一使用 INMP441，避免按 SPH0645 文档接错。
- 增加 `microphone`、`speaker`、`haptic`、`imu`、`mute` 五个台架诊断入口。

## 暂时不要购买

- 锂电池、充电附件、贴肤材料、安全脱离扣。
- 三套重复器件和三套外壳。
- 静音开关、状态灯与最终小型 PCB。
- 任何宣称可直接替代但没有完整引脚图和数据表的模块。

## 到货后的唯一正确顺序

1. 主板只接 USB，先验收屏幕、BLE 和 `imu` 诊断。
2. 断电后只接 INMP441，比较安静与近讲时的 `microphone` 峰值。
3. 断电后改接 MAX98357A 与扬声器，运行 660 Hz 短音 `speaker` 诊断。
4. 最后连接 GPIO4 对应 MOS 触点上的 1027 马达，运行 `haptic`；马达不能直接接普通 GPIO。
5. 所有模块联合运行后再测回声、复位、发热和基本功耗。
6. 一套完整通过后，才开始 EVT-B 集成和电池选型。
