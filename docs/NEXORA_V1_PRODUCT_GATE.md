# NEXORA CORE V1 产品门槛

冻结日期：2026-08-03

## V1 核心承诺

NEXORA CORE V1 是一个能够佩戴、能够持续成长、能够通过手机可靠联网的原创数字生命。第一版必须把“每天愿意带着并自然说话”做好，不以功能数量作为成熟度。

V1 主链路只有五步：

1. 用户在手机上选择 LUMO、VEYR 或 AERA，并完成命名与诞生。
2. 手机与用户拥有的 NC-01 完成安全配对。
3. 项链通过抬起或用户操作进入一次明确的语音会话。
4. 回答、动作、名字、人格、记忆和成长状态在项链、手机、电脑保持一致。
5. 用户能够导出、迁移、撤销设备并删除数据。

## V1 范围

必须完成：

- NC-01 实体项链、手机网关、三条角色路线、九个成长形态。
- 文字与语音对话、可打断播放、结构化人格和有边界的长期记忆。
- 加密跨设备同步、旧设备撤销、可信设备迁移和数据删除。
- macOS 与 Windows 电脑控制的白名单动作。
- 签名固件升级、失败回滚、物理麦克风静音和低电量保护。

V1 只做一个真实家居网关，平台在 EVT 完成前冻结。没有真实设备回执时，伙伴不得声称控制成功。

暂不进入 V1：

- 开放式插件市场和任意系统命令。
- 多人社交、公开角色交易和用户生成角色模型。
- 项链直接连接公网或保存完整对话。
- 同时接入多个家居生态。

## 阶段门槛

### EVT 工程验证

- 至少 3 台可运行首件。
- BOM 器件冻结，完成装配、温升、音频、BLE、显示、IMU、静音、拉力和跌落测试。
- 三台样机连续运行七天，有完整故障记录。

### DVT 设计验证

- 至少两种真实手机系统完成首次配对、后台重连、语音与升级。
- 1000 次 BLE 快照失败率低于 1%。
- 典型陪伴续航达到 8 小时初始目标，外壳和声学结构完成修订。
- Secure Boot、Flash Encryption、签名 OTA 和回滚通过。

### 保密用户测试

- 20 位用户连续使用 30 天。
- 记录日活、七日留存、对话完成率、回答延迟、记忆纠错率、误唤醒和设备掉线。
- 所有严重隐私、安全、过热和数据丢失问题清零后才进入下一阶段。

### 外部发布

- 完成销售地区要求的硬件、无线、电池、材料和隐私合规评审。
- 手机、桌面与固件均具备签名发布、自动更新、回滚和事故响应。
- 建立客服、退换货、账号恢复、服务状态和云端成本监控。

## 可执行报告

首件 BOM 位于 `hardware/soulmate-pendant/evt/nc01-bom-v1.json`，验收状态位于 `hardware/soulmate-pendant/evt/nc01-acceptance-v1.json`。执行：

```bash
npm run product:readiness
```

只有带证据的检查才能标记为 `passed`。发布流水线可使用 `npm run product:readiness -- --require-ready` 阻止未通过 EVT 的版本进入下一阶段。
