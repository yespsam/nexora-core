# NEXORA CORE 完成度审计

审计日期：2026-07-30

## 当前结论

- 数字体验演示完成度：**96%**。首次开机、三种初始伙伴、九套原生 3D 成长形态、命名、生日、性别、性格、独立声线与对话人格、文字对话、长期记忆、导入导出、PWA 外壳、240×240 项链圆屏、三端本机连续性和恢复码式端到端加密跨设备同步已经形成完整演示主流程。
- 产品工程完成度：**48%**。NC-01 CAD、STL、3MF、PETG 数字切片、圆屏固件、54 套 LittleFS 互动角色资源、手机端 BLE 快照写入与密文云同步已经完成；量产云端的数据分类、PostgreSQL 迁移和设备事件协议已形成设计基线，但尚未部署真实数据库。实体首件、真屏刷机联调、音频链路、电池热安全和家居网关仍未完成。
- 当前版本可以用于产品走查和用户体验测试，不能表述为可量产硬件或已完成家电控制。

## 本轮验收记录

- Node 自动化测试：86/86 通过，覆盖三只伙伴人格路由、共享骨骼兼容、语音回声边界、公开运行文件白名单、跨窗口连续性协议、恢复码边界、AES-GCM 加解密、云端令牌哈希、设备事件边界和数据库安全结构。
- 电脑虚拟测试台：13 项路径完成，包含虚拟 BLE、共享模型动画切换、完整状态机、连续对话、三端身份连续与真实声线接口；静态服务器完成 12/13，缺少的云端声线项已通过本机 Netlify 函数独立返回有效音频。
- 移动视口：390 x 844，无横向溢出；输入栏与底部导航无重叠。
- 桌面视口：1440 x 900，无页面溢出。
- 项链圆屏：嵌入模式严格为 240 x 240；三条路线九个成长形态均通过圆周像素安全检查，角色资源加载成功。
- NC-01 固件：ESP32-S3 应用编译通过，Flash 使用 595813 / 3145728 bytes，RAM 使用 30452 / 327680 bytes；54 套角色资源共 6221232 bytes，8 MB LittleFS 内容校验和 16 MB 工厂镜像合并通过。
- 首次开机：完整通过；本地无云函数时声线试听显示“声音暂不可用”，不再误报成功。
- 对话：输入、上下文回退、成长和记忆写入通过。
- 数据：JSON 导出、同文件导入和替换确认通过。
- 加密同步：本机 Netlify 端到端测试完成密文上传、新设备恢复、错误密钥拒绝、版本冲突保护和云端副本删除；请求正文不含名字、记忆、对话或解密密钥。
- 实体云端基线：已新增 PostgreSQL 初始迁移、Row-Level Security、事件不可变触发器、设备公钥约束、恢复密钥包和保留策略；当前未连接生产数据库，不计为已上线能力。
- 缓存：PWA 导航改为网络优先，解决已发布新版本但用户仍看到旧页面的问题。
- 连续性边界：已完成无需账号的恢复码式跨网络同步；恢复码由用户自行保管，不提供项目方找回能力，也尚未替代实体项链 BLE 验证。

## 发布前阻断项

1. 打印 NC-01 实体首件，完成主板、电池、USB-C、导光条和音频器件装配。
2. 完成 5/10/20 N 吊环拉力、60 分钟充电温升、跌落、绝缘和贴肤材料测试。
3. 确定手机网关协议，并以真实命令回执作为家电控制成功的唯一依据。
4. 部署量产 PostgreSQL 与对象存储，实现设备注册、签名事件、撤销、密钥轮换和从现有 Blob 同步双写迁移。
5. 将九套 3D 进化形态转换为实体圆屏低功耗显示资源，并验证刷新速度与功耗。
6. 完成 iOS Safari、Android Chrome、桌面 Chrome/Edge 以及真机蓝牙和语音兼容测试。
