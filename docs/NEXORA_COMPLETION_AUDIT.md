# NEXORA CORE 完成度审计

审计日期：2026-07-31

## 当前结论

- 数字体验演示完成度：**96%**。首次开机、三种初始伙伴、九套原生 3D 成长形态、命名、生日、性别、性格、独立声线与对话人格、文字对话、长期记忆、导入导出、PWA 外壳、240×240 项链圆屏、三端本机连续性和恢复码式端到端加密跨设备同步已经形成完整演示主流程。
- 产品工程完成度：**52%**。NC-01 CAD、STL、3MF、PETG 数字切片、圆屏固件、54 套 LittleFS 互动角色资源、手机端 BLE 快照写入与密文云同步已经完成；私有测试云、生产数据库迁移和匿名访问门禁已上线，设备事件 API 仍保持关闭。实体首件、真屏刷机联调、音频链路、电池热安全和家居网关仍未完成。
- 当前版本可以用于产品走查和用户体验测试，不能表述为可量产硬件或已完成家电控制。

## 本轮验收记录

- Node 自动化测试：149/149 通过，覆盖托管模型密钥隔离、上下文与偏好连续性、三只伙伴人格路由、九形态共享骨骼兼容、11 种语义动作配置、语音回声边界、多段识别、收音超时与可恢复错误提示、公开运行文件白名单、跨窗口连续性协议、恢复码边界、AES-GCM 加解密、云端令牌哈希、设备事件边界、Identity 身份映射、全站资源门禁、Netlify 数据库角色安全结构、加密快照完整性、双写开关、签名读回和网络丢包幂等恢复。
- 电脑虚拟测试台：15 项路径包含虚拟 BLE、九形态逐一渲染、三路线 33 次动作切换、完整状态机、连续对话、三端身份连续与真实声线接口；本地静态服务器负责模型和三端状态验收，对话与声线必须在部署后的私有云环境实测，不能用本地固定数据替代。
- 移动视口：390 x 844，无横向溢出；输入栏与底部导航无重叠。
- 桌面视口：1440 x 900，无页面溢出。
- 项链圆屏：嵌入模式严格为 240 x 240；三条路线九个成长形态均实际渲染成功，33/33 动作切换不重建模型；待机与设备状态保持正面稳定，对话动作使用头部、脊柱与手臂的受控骨骼微动。
- NC-01 固件：ESP32-S3 应用编译通过，Flash 使用 595813 / 3145728 bytes，RAM 使用 30452 / 327680 bytes；54 套角色资源共 6221232 bytes，8 MB LittleFS 内容校验和 16 MB 工厂镜像合并通过。
- 首次开机：完整通过；本地无云函数时声线试听显示“声音暂不可用”，不再误报成功。
- 对话：真实 Kimi 四轮连续测试通过，能承接辣火锅场景、推断后续饮品，并以最新偏好覆盖旧的咖啡偏好；云模型凭据不再进入浏览器。
- 数据：JSON 导出、同文件导入和替换确认通过。
- 加密同步：本机 Netlify 端到端测试完成密文上传、新设备恢复、错误密钥拒绝、版本冲突保护和云端副本删除；请求正文不含名字、记忆、对话或解密密钥。
- 实体云端闭环：PostgreSQL 16 真实迁移与最小权限角色通过；手机、项链、桌面 3 台虚拟设备写入 1000 条 AES-GCM 密文事件，分页总数和事件 ID 唯一性一致；重复投递幂等、跨租户不可见、撤销设备禁止读写、密钥轮换、恢复密钥往返和账号删除均通过。Netlify production 数据库已连接且迁移成功，但设备 API 总开关仍关闭，不计为已上线用户能力。
- 私有测试云适配：Netlify Identity 用户稳定映射为内部 RLS UUID，客户端身份字段被覆盖，所有写请求执行同源校验；关闭总开关时 API 返回 404。伪 Identity 会话到 Netlify Function、真实本机 PostgreSQL、设备事件和删除任务的 3 设备链路通过。
- Free 保密门禁：正式域名未登录页面和模型请求均以 302 重定向到独立访问页，设备云 API 返回 401，状态接口仅返回 `authenticated:false`；登录、邀请、确认、找回和退出接口执行同源校验，回跳地址限制为站内；受保护响应不进入共享缓存，退出清理旧 PWA 缓存。桌面 1440×900 与手机 390×844 无横向溢出。
- 依赖审计：经授权执行的生产依赖审计为 0 个漏洞。安装过程提示的 8 个高危公告只可能位于开发依赖范围；完整开发依赖图尚未获单独外传授权，不能执行破坏性 `npm audit fix --force`。
- 缓存：PWA 导航改为网络优先，解决已发布新版本但用户仍看到旧页面的问题。
- 连续性边界：已完成无需账号的恢复码式跨网络同步；恢复码由用户自行保管，不提供项目方找回能力，也尚未替代实体项链 BLE 验证。
- 隔离云端生命周期：5 条密文事件写入、3 份快照保留、重复快照幂等、AES-GCM 往返、跨 owner 阻断、删除取消和到期发现均通过；定向维护处理 1 条、失败 0 条并删除 3 个对象，复核确认账户、快照索引、删除请求和对象存储四项全部清理。临时数据库连接串已删除，维护开关已恢复为关闭。
- 受控双写准备：旧同步保持权威并先完成；新客户端只在独立服务端开关开启时创建加密设备状态，生成 ES256 签名的 AES-GCM 迁移事件，读回核对事件哈希与明文摘要。注册或事件响应丢失可用原 ID 幂等恢复，新路径故障不影响旧同步成功状态；真实一周对账尚未开始。
- 私有会话退出：真实受邀会话从设置页退出后跳转 `/access/?signedOut=1`，页面确认设备缓存已清理；密码恢复表单与返回登录流程通过，邮件投递待正式发件域复测。
