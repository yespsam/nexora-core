# NC-01 圆屏运行界面

项链端不是手机页面的缩小版。当前 NC-01 CAD 对应非触控版 Waveshare ESP32-S3-LCD-1.28，因此圆屏只显示伙伴和即时状态，交互来自语音、六轴传感器、手机 BLE 网关、震动和四段导光条。

浏览器中的交互预览位于 `pendant-display/`，只显示 WebGL 3D 角色，不再提供 2D 造型切换。普通模式同时显示 NC-01 外壳与测试信号，`pendant-display/?embedded=1` 只保留 `240 x 240` 圆屏画面。

## 屏幕层级

1. 顶部安全区：伙伴名、BLE 状态和电量。
2. 中央：当前路线和成长阶段的伙伴形象。
3. 底部安全区：不超过 16 个汉字的状态或主动提醒，以及共鸣值。
4. 外部四段导光条：倾听为青色常亮，思考为交替青色，说话为珊瑚色，低电量为红色闪烁。

## 固件接入边界

- GC9A01A 输出固定为 RGB565 `240 x 240`。
- 抬腕或拿起由 QMI8658 唤醒屏幕；当前非触控主板不绑定点击手势。
- 浏览器测试台中的单击、双击和长按只用于模拟状态输入，不属于实物操作合同。
- 唤醒词进入 `listening`，模型请求进入 `thinking`，TTS 播放进入 `speaking`。
- 手机通过 BLE GATT 同步身份、成长阶段、共鸣值和短提醒，不同步完整聊天记录。
- 电量低于 10% 时覆盖普通状态进入 `low-power`；充电状态优先保留。

字段与安全区域见 `display-contract.json`。实际刷机前仍需确定麦克风、扬声器、震动马达、LED 驱动和 BLE 服务 UUID。
